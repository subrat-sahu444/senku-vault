## 🚀 Quick Start (Local Run)

### Windows 1-Click Launch:
Double-click `start.bat` or run:
```bash
./start.bat
```
The server will boot and automatically open **http://localhost:3000** in your browser!

### Manual Launch (Node.js):
```bash
# Clone the repository
git clone https://github.com/subrat-sahu444/senku-vault.git
cd senku-vault

# Start the Senku Engine
npm start
```
Open **[http://localhost:3000](http://localhost:3000)**.

## ☁️ Public Cloud Deployment (Deploy for Everyone!)

### Option 1: 1-Click Docker Deployment
Senku Vault includes a production-ready `Dockerfile` bundled with Node.js, Python, FFmpeg, and `yt-dlp`:

```bash
docker build -t senku-vault .
docker run -p 3000:3000 senku-vault
```

### Option 2: Free Hosting on Render
1. Push this repository to your GitHub account (`subrat-sahu444/senku-vault`).
2. Go to [Render.com](https://render.com) and click **New + > Web Service**.
3. Connect your `senku-vault` repository.
4. Select **Docker** environment (Render will automatically detect `Dockerfile` or `render.yaml`).
5. Click **Deploy Web Service** — your app is now live for everyone with a free public `https://senku-vault.onrender.com` URL!

### Option 3: Railway / Fly.io
Deploy directly via GitHub repository integration — Dockerfile will auto-configure everything.
